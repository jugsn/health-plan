总原则:一次只改一件事,系统跑 12 周

你的情况是超重明显 + 作息混乱常熬夜 + 运动不规律。这三件事有因果关系:睡不好 → 饥饿素升高、意志力下降 → 吃得多、练得少 → 更胖更累 → 更晚睡。所以计划的顺序是:先稳住起床时间,再稳住饮食结构,最后加运动负荷。反过来做一定失败。

减脂:四个杠杆,按优先级排

优先级杠杆具体做法
1蛋白质每餐一掌心大小的肉/鱼/蛋/豆制品,全天 1.6–2.2g/kg 体重(80kg ≈ 130–175g)。蛋白最高饱腹、最保肌肉,是第一位。
2热量缺口每天少吃 300–500 kcal,不节食。先删三个最便宜的:含糖饮料、油炸/零食、睡前加餐。
3力量训练每周 3 次,全身动作:深蹲/硬拉类、推、拉、核心。每次 40 分钟。减脂期力量训练的作用是保住肌肉,让掉的是脂肪。
4日常步数8000–10000 步。耗能大、不增饥饿、恢复快,是性价比最高的热量消耗方式。
  • 速度:每周减 0.5–1% 体重(90kg → 每周 0.45–0.9kg)。快过这个数,掉的多半是肌肉,必反弹。
  • 平台期(连续 2 周体重不动):先查执行率——执行率 <90% 就先补执行,不改计划;执行率没问题,再把步数 +1500 或热量 -100kcal,只改一个。
  • 体重波动是正常的:一天涨 1–2kg 全是水和食物残渣。永远只看 7 天平均线,数据页已自动画出。

睡眠:熬夜修正方案(针对你)

顺序动作为什么
①先固定起床时间,哪怕前一晚只睡了 4 小时,第二天也照常起。用闹钟放客厅。起床点是生物钟的锚。先锁起床,入睡时间会自己跟上来。这是最重要的一步。
②起床后 30 分钟内出门见光 10–15 分钟(阴天也有效)。抑制褪黑素、设定 16 小时后的睡眠驱动力,当天晚上会自然困。
③咖啡因截止 14:00;下午 2 点后不喝奶茶/功能饮料。咖啡因半衰期 5–6 小时,下午 3 点喝 = 睡前体内还有一半。
④睡前 1 小时降档:灯光调暗、手机放到床外充电、只做低刺激事(洗漱、拉伸、纸质书/听书)。屏幕蓝光 + 内容刺激直接推迟入睡;放床外是唯一被反复验证有效的办法。
⑤卧室:凉(18–22℃)、暗、静;床只用来睡觉。体温下降是入睡信号;床上刷剧会让大脑把床和清醒绑定。
⑥周末起床时间浮动 < 1 小时,不补觉超过 1 小时。"社交时差"是周一最困、最容易暴食的元凶。

节奏建议:如果现在 1–2 点睡,不要一步到 23 点。每 3 天把上床时间提前 15 分钟,同时起床时间不动,2–3 周平移完成。目标:23:30 上床,07:00 起床,睡 7.5 小时。

拒绝与社交:把"变强"拆成 7 级可练习的动作

你觉得自己软弱,大概率是因为:每次拒绝都是临场发挥,而对方在主场。解法不是打鸡血,是提前备好话术 + 从低风险场景开始重复,直到它变成默认反应。

  • 度量:每周至少 3 次主动表达/拒绝,记录在"成长"页。看的不是成功几次,是难度评分有没有下降——同样的事从 8 分降到 4 分,就是进步。
  • 主战场:第 4 级(酒局、夜宵、劝奶茶)直接关系你的减脂和睡眠。每周至少成功拒绝 2 次,这一项顶其他所有。
  • 失败处理:没扛住不算失败,当晚写进练习记录("我说了行,然后后悔了")。能识别出"我又自动答应了",本身就是进步。
  • 心态:你不是变冷漠,你是把过去乱开的门一扇扇关上。真正的关系经得起一次拒绝。

执行规则:让计划活下去

  • 只盯行为目标,不盯体重。体重是滞后指标,行为是唯一你能控制的东西。
  • 80% 规则:每周允许 2 次自由餐、1 个完全休息日。计划有弹性才走得远。
  • 断 1 天不算失败,永远不断 2 天。漏了训练就出门走 20 分钟;熬了夜第二天照常起床。恢复速度是唯一重要的指标。
  • 习惯叠加:新习惯挂在旧习惯后面——刷完牙就称重、吃完午饭就出门走、手机充电就放客厅。
  • 环境设计:零食不买进家门;水果放视线高度;床头只留书。
  • 每周只改一个变量。同时改三样,你永远不知道是什么起作用了。

四条铁律

  • 拒绝不需要理由。一给理由,对方就开始讨价还价。
  • 先延迟再回答:"我先看看安排,晚点回你。"打断你的自动答应。
  • 你拒绝的是这件事,不是这个人。对方的失望由对方负责。
  • 短期尴尬 vs 长期怨恨,永远选前者。答应后心里憋着,关系反而更糟。

周复盘

云同步 · 手机和电脑共用一份数据

数据默认只存在当前浏览器。配置一次后,所有设备通过你的 GitHub 私密 Gist 自动合并——按天/按周合并,两边同时改也不会互相覆盖。

一次性设置(约 5 分钟):
1. 电脑浏览器打开 github.com/settings/tokens/new,名称随意,只勾选 gist,点 Generate token,复制 ghp_ 开头的字符串
2. 粘贴到上面的令牌框 → 点 ① 创建同步空间(会自动生成私密 Gist 并填好 ID)
3. 手机浏览器打开本页 → 粘贴同一个令牌和 Gist ID → 点 ② 立即同步
4. 手机 Chrome 菜单 → 添加到主屏幕,以后从桌面图标打开
令牌只存在各设备本地、绝不会写进同步数据;Gist 是私密的。
